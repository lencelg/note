# lec1
第一节主要是relation model中的运算关系的介绍

relation algebra
|type| example| description|
|---|---|---|
| SELECT |`SELECT * FROM R WHERE a_id='a2' AND b_id>102;`| Choose a subset of the tuples in a relation satisfying selection predicate.|
| PROJECTION|`SELECT b_id-100, a_id FROM R WHERE a_id = 'a2';`|Generate a relation with tuples that contains only the specified attributes. |
| UNION| `(SELECT * FROM R) UNION (SELECT * FROM S);` | (并集) Generate a relation that contains all tuples that appear in either only one or both input relations, eliminating duplicates.|
| INTERSECTION| `(SELECT * FROM R) INTERSECT (SELECT * FROM S);`| 交集
| EXCEPT| `(SELECT * FROM R) EXCEPT (SELECT * FROM S);`| 差集
| PRODUCT| `SELECT * FROM R CROSS JOIN S;`| 笛卡尔积
