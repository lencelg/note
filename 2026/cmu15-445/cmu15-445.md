下面介绍windows function(窗口函数)

普通聚合（GROUP BY）会把多行压成一行，而窗口函数会在每一行上显示聚合或排名结果，同时保留所有原始行。

```sql
函数名(列名) OVER (
    PARTITION BY 分组列   -- 可选：定义窗口分组
    ORDER BY 排序列       -- 可选：定义窗口内排序
    ROWS / RANGE ...      -- 可选：进一步限定窗口范围
)
```

- **`OVER`** 关键字标志这是一个窗口函数。
- **`PARTITION BY`** 将数据分成若干“分区”，窗口函数在每个分区内独立计算（类似 GROUP BY 但不合并行）。
- **`ORDER BY`** 决定窗口内行的顺序，对排名类函数必须，对聚合类可选。

```sql
SUM(销售额) OVER (PARTITION BY 部门 ORDER BY 月份) -- 部门内逐月累计销售额
```

每个班级内按分数从高到低排名
```sql
SELECT *,
       RANK() OVER (PARTITION BY 班级 ORDER BY 分数 DESC) AS 班内排名
FROM 成绩表;
```
