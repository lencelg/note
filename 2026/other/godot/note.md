= Start

Godot 配备了成熟的游戏编辑器, 其集成工具可以满足最常见的需求
- 代码编辑器
- 动画编辑器
- 图块地图编辑器 
- 着色器编辑器
- 调试器
- 性能分析器
- ......


== concepts

在 Godot 中，游戏就是一棵由**节点**构成的树，节点可以分组形成**场景**。然后你还可以将这些节点**连起来**，让它们通过**信号**进行通信。

Godot 自带内置的类参考手册。
- 在脚本编辑器中 `Ctrl + 点击`类名、函数名、内置变量。
- 在编辑器中任意位置按下 `F1` (或在带有 `Fn` 键的笔记本电脑上按下 `Fn + F1`)。
- 点击 Script 主屏幕右上角的“搜索帮助”按钮。
- 点击“帮助”菜单的“搜索帮助”。

Godot 提供了专门的 2D 和 3D 渲染引擎
- 2D 场景的基础单位是像素

**尽管引擎是独立的**，但可以在 3D 中渲染 2D、在 2D 中渲染 3D，也可以在 3D 世界之上覆盖 2D 精灵和界面。

== GDScript

Godot 还有一些特殊函数具有一定的自定义功能.

以 `_process()` 函数为例。

```gdscript
func _process(delta):
    rotate(0.05)
```

`_process()`（运行处理） 函数之所以得名，是因为它进行计算或持续的操作。

Godot每一frame（帧）都运行这个函数一次。

函数名称前面的下划线 **_** ,这是一个约定俗成的事情，来协调程序员的工作

`delta` 是 Godot 完成前一帧所需的时间，以秒为单位。

它的值非常小，因为每秒会出现很多帧。

它随着每一帧不同而改变，因为 Godot 需要或多或少的时间来处理每一帧。 

引擎会在内存中创建每个对象或节点时调用 `_init()`

=== dealing with inputs

Godot 中，有两个主要工具来处理玩家的输入：
- *_unhandled_input()*
- *Input* 单例

=== signals

最简单的就是*button*的`pressed()`函数了，然后可以通过编辑器的来自动`connect()`到其他的scene

另外一种就是通过代码来进行信号连接, 示例是一个`Timer`类

想要在场景实例化时连接信号，可以使用 `Node._ready()` 内置函数来实现，当节点完全实例化时，引擎会自动调用该函数。

= First 2D

**小技巧**:

`$` 是 `get_node()` 的简写。因此，`$AnimatedSprite2D.play()` 与 `get_node("AnimatedSprite2D").play()` 相同。

在 GDScript 中，`$` 返回从当前节点开始的相对路径上的节点，如果找不到该节点，则返回 `null`。当前 AnimatedSprite2D 是该节点子节点，因而可以使用 `$AnimatedSprite2D` 以获取。

可以使用 `clamp()` 来防止它离开屏幕。 clamp 一个值意味着将其限制在给定范围内。

== 游戏信息显示

`CanvasLayer` 节点可以让我们在游戏的其他部分的上一层绘制 UI 元素，这样它所显示的信息就不会被任何游戏元素（如玩家或敌人）所覆盖。

UI 元素的基本节点是 `Control`。要创建 UI，我们需使用 `Control` 下的两种节点：`Label` 和 `Button`。
